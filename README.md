# 酒馆小工具合集（st-molot-kit）

| 模块 | 说明 |
|------|------|
| API 自动重试 | 对话生成失败时自动重试 |
| 角色置顶与归档 | 列表置顶 / 归档隐藏 |
| 开场导入导出 | 主开场 / 候选开场：导出到剪贴板、从剪贴板导入覆盖（适合拿到 Grok 等处汉化） |
| 复制聊天 | 最近 N 条纯聊天复制到剪贴板 |
| 开场 AI 汉化 | 仅扩展设置里可选；编辑页已改为导入导出 |

**不含** [Megumin Suite 汉化版](https://github.com/molot23/Megumin-Suite-zh)。

## 安装

```
https://github.com/molot23/st-molot-kit
```

## 开场汉化（推荐流程）

1. 角色编辑：点 **导出开场** / 打开「其他开场」后点 **导出候选**（或每条旁的导出）
2. 粘贴到 Grok 等处汉化（保留 `{{user}}` / `{{char}}`）
3. 复制译文 → 回酒馆点 **导入开场** / **导入候选**（Android 会弹出粘贴框，长按粘贴即可）
4. **保存角色卡**

第一次点导出时会把该卡原文备份到本地（localStorage）；可用「还原」回到备份。

导出走纯文本（方便外面汉化）；导入仍兼容旧标记格式。候选多条时用「【候选N】」分隔。
