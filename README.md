# 酒馆小工具合集（st-molot-kit）

| 模块 | 说明 |
|------|------|
| 角色置顶与归档 | 列表置顶 / 归档隐藏 |
| 开场导入导出 | 主开场 / 候选：剪贴板导出导入（推荐用于外部汉化） |
| 复制聊天 | 最近 N 条纯聊天复制到剪贴板 |

所有设置集中在扩展设置 → **酒馆小工具合集**。危险操作（还原开场、清空置顶归档）在「显示高级选项」里。

**不含** API 自动重试（请用你自己的替代扩展）。**不含** [Megumin Suite 汉化版](https://github.com/molot23/Megumin-Suite-zh)。已移除开场 AI 汉化。
