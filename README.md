# 酒馆小工具合集（st-molot-kit）

把常用小插件合成一个扩展，少装几个：

| 模块 | 说明 |
|------|------|
| API 自动重试 | 对话生成失败时自动重试（原 st-api-auto-retry） |
| 角色置顶与归档 | 列表置顶 / 归档隐藏（原 st-char-pin-archive） |
| 开场汉化 | 「汉化开场」：第一条消息 + 全部候选开场；走当前 AI；保留 `{{宏}}` |
| 聊天分享 txt | 输入栏旁分享图标：打包最近 N 条纯聊天为 `.txt`，优先系统分享，否则下载 |

**不含** [Megumin Suite 汉化版](https://github.com/molot23/Megumin-Suite-zh)（请继续单独装）。

## 安装

```
https://github.com/molot23/st-molot-kit
```

若以前装过单独的自动重试 / 置顶归档：先装合集确认正常，再禁用删除旧扩展。

## 聊天分享用法

点输入栏左侧 **三条杠菜单** → **分享聊天为 txt**（输入栏旁图标仍保留作备用） → 生成 txt（默认最近 100 条，扩展设置可改；`0` = 全部）→ 手机上弹出系统分享选 Grok；桌面端一般会下载文件。

只含对话正文，不含角色卡 / Megumin 记忆。

## 首条汉化用法

打开角色编辑 → 点 **汉化开场**（或扩展设置「立即汉化」）→ **保存角色卡**。
